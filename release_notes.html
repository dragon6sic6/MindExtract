What's New in 2.1.3

  • Download several qualities of the same video — grab 720p and then 1080p back-to-back and you'll get both files. Each download now saves with its resolution in the name (e.g. "… 1080p.mp4") instead of the second one silently doing nothing.
  • See the size before you download — the quality menu now shows each option's file size (e.g. "1080p · ~258 MB") and marks the recommended pick, so there are no surprises.
  • Looks right at any window size — resize the window small or go fullscreen and text no longer crams or breaks in the middle of a word. The transcript header, speaker list, and other panels all adapt cleanly.
  • Switch AI models right in the chat — a new model picker in the transcript chat lets you change between Apple Intelligence, Ollama, OpenAI, and Anthropic without going to Settings.
  • Clearer AI messages — when Apple's on-device model declines a question, you now get a helpful explanation and a nudge to switch providers, instead of a cryptic error.
  • Polish — the Export button now matches the rest of the app, and buttons stay consistent throughout.
