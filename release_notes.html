What's New in 2.1.5

More choice in AI providers — pick the model that suits you.

More AI providers for summaries & chat

  • New cloud providers — alongside OpenAI and Anthropic you can now use Google Gemini, xAI Grok, Mistral (European, EU-hosted), Groq (fast), and OpenRouter (one key, many models).
  • Custom endpoint — point MindExtract at any OpenAI-compatible server, including your own self-hosted one.
  • Set up in seconds — each provider shows whether it's ready to use, links straight to where you get a key, and a Test button confirms the key works.
  • Local options stay front and center: Apple Intelligence and Ollama run fully on your Mac.

Refinements

  • API keys are tidied automatically (a stray space or newline from pasting no longer causes sign-in errors).
  • Long transcripts are handled correctly for every model, regardless of its context size.
  • Clearer notes on where your data goes for each provider — the on-device options remain the private default.
